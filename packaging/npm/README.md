# Floe (`@leo-luxy/floe`)

**Floe** is a cross-platform quantitative stock screener, trend-following backtester, and AI investment research workbench for macOS, Windows, and Linux.

## Quick Start

```bash
# Install globally
npm install -g @leo-luxy/floe

# Launch native desktop window
floe

# Or launch in your default web browser
floe --web

# Run environment diagnostics
floe --doctor
```

> Tip (Mainland China network): If downloading the prebuilt runtime from GitHub Releases is slow on first launch, pass a mirror prefix:
> ```bash
> FLOE_GITHUB_MIRROR=https://ghfast.top/ floe
> ```
